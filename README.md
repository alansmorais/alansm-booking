# AlanSM Booking

Standalone multi-tenant booking SaaS for barbershops, beauty salons, and nail professionals.

## Development safety

- `main` is reserved for stable, reviewed work.
- `preview` is the development and validation branch.
- This repository is independent from the AlanSM Solutions marketing website.
- Pilot architecture: Google Sheets + Google Apps Script, with the Firebase prototype retained separately as a rollback/reference option.
- No production deployment, external service activation, billing, DNS, or live data changes are authorized by repository initialization.

## Status

Repository initialized. Application source and prior implementation reports still need to be imported or reconstructed and verified.
